# The `_` namespace

This namespace contains general evals for tbhb-dev work that don't belong to one project, such as comparisons between agent harnesses. Each eval gets its own directory here, `e-NNNNNN-<slug>/`, with its design in `README.md`. Its ID takes the form `_/E-NNNNNN`, and the namespace numbers its evals from its own six-digit sequence. See [PROTOCOL.md](../../PROTOCOL.md).
